Prompt inicial: Necesito que me hagas un prompt para hacer una página Web que se basara en una tienda online de objetos medievales y antiguos reales rerstaurados llevada por arqueólogos y historiadores. con las siguientes instrucciones: Inicialmente buscaremos diseños sencillos que no utilicen \*frameworks\* CSS como Tailwind o Bootstrap, es decir, que solamente utilicen código HTML y CSS.  IMPORTANTE: Has de hacerla con HTML y CSS puro. Dicho prompt se lo voy a mandar a stich, la IA  o kimi. 



Respuesta: 



Quiero que diseñes y desarrolles la interfaz de una tienda online especializada en objetos medievales y antiguos reales, restaurados y documentados, gestionada por un equipo de arqueólogos, historiadores y especialistas en conservación.



El objetivo es crear una web que transmita autenticidad, rigor histórico, confianza, exclusividad y elegancia, alejándose completamente del aspecto de una tienda de disfraces, una web de fantasía o una tienda genérica de antigüedades.



RESTRICCIONES TÉCNICAS — MUY IMPORTANTE



La web debe estar construida EXCLUSIVAMENTE con HTML y CSS puro.



* NO utilizar Tailwind CSS.



* NO utilizar Bootstrap.



* NO utilizar Bulma, Foundation ni ningún otro framework CSS.



* NO utilizar frameworks frontend como React, Vue, Angular, Svelte, etc.



* No depender de librerías de componentes externas.



* El diseño debe poder entenderse y mantenerse fácilmente utilizando únicamente HTML y CSS.



* Utiliza CSS moderno cuando sea apropiado: Flexbox, CSS Grid, variables CSS, clamp(), min(), max(), aspect-ratio, transition, etc.



* Utiliza JavaScript únicamente si fuese estrictamente necesario para una interacción concreta. Si una funcionalidad puede resolverse con HTML y CSS, prioriza esa solución.



* El código debe ser limpio, semántico, organizado y fácil de modificar posteriormente.



* La web debe ser responsive y funcionar correctamente en móvil, tablet y escritorio.



* No quiero un diseño que dependa de una plantilla prediseñada.



**CONCEPTO VISUAL**



* La estética debe inspirarse en:



* Manuscritos medievales.



* Museos y exposiciones arqueológicas.



* Archivos históricos.



* Bibliotecas antiguas.



* Gabinetes de curiosidades.



* Piedra, madera, pergamino y metal envejecido.



* Fotografía editorial de piezas arqueológicas.



* Catálogos de subastas y colecciones históricas.



Sin embargo, el resultado debe ser moderno, limpio y elegante, si permito un toque maximalista.



Evita caer en una estética excesivamente fantástica o temática.



**NO quiero:**



* Castillos dibujados.



* Dragones.



* Fuentes medievales difíciles de leer.



* Efectos dorados exagerados.



* Aspecto de videojuego.



* Aspecto de tienda de disfraces.



* Diseño barroco o visualmente saturado.



La sensación general debería ser la de una mezcla entre museo, casa de subastas especializada y boutique de objetos históricos.



**PALETA DE COLORES**



Utiliza una paleta sobria y natural, por ejemplo:



* Marfil / pergamino para fondos.



* Negro carbón o marrón muy oscuro para textos.



* Marrones y tonos tierra.



* Gris piedra.



* Verde oliva o verde oscuro como color secundario.



* Bronce o latón envejecido para pequeños detalles.



Los colores deben utilizarse con moderación.



El contraste y la legibilidad tienen prioridad sobre la decoración.



**TIPOGRAFÍA**



Utiliza una combinación de:



* Una tipografía serif elegante para títulos y elementos históricos.



* Una tipografía sans-serif limpia para navegación, botones, precios, filtros y textos funcionales.



La tipografía debe transmitir cultura y tradición, pero seguir siendo perfectamente legible.



Evita las tipografías medievales o góticas excesivamente ornamentadas.

ElISIO
